# SYSTEM SPECIFICATION & FULL BUILD PROMPT FOR REPLIT AGENT

## PROJECT TITLE
**Lycée Mustapha El Maâni - Educational Club Digital Student Badge & QR Attendance System**

---

## 1. EXECUTIVE SUMMARY & OVERVIEW
Build a complete, lightweight, highly secure, and mobile-responsive Full-Stack Web Application for managing student memberships and weekly attendance for an educational school club at **Lycée Mustapha El Maâni (ثانوية مصطفى المعاني التأهيلية)** in Casablanca, Morocco.

### Core Value Proposition:
1. **Paperless Digital Badges**: Eliminates physical printing by generating high-resolution digital image badges containing encrypted QR codes sent directly to students' WhatsApp or phones.
2. **Anti-Forgery Encryption (Crypto-Secured)**: Standard phone camera scanners must read gibberish/encrypted ciphertext. Only the authenticated admin web scanner application, equipped with a server-side AES-256 secret decryption key, can validate the token, match student identity, and record attendance.
3. **Instant Mobile Scan (Friday Sessions)**: Allows the admin/supervisor to scan digital student badges using their smartphone camera at the entrance every Friday (14:00 - 18:00).
4. **Automated Attendance Reporting**: Tracks who attended, flags absences, checks parental authorization status (A1/A2 forms), and exports clean Excel/PDF reports after each session.

---

## 2. SYSTEM ARCHITECTURE & TECH STACK

### Backend & Server Framework:
- **Runtime**: Node.js (v18+ or v20+)
- **Web Framework**: Express.js
- **Database**: Replit Database (`@replit/database`) OR SQLite / Supabase (Free Tier) as a fallback persistent store.
- **Cryptography**: Node.js native `crypto` module using **AES-256-CBC** symmetric encryption with HMAC-SHA256 integrity verification.

- **Rendering Engine**: HTML5, Modern CSS3 (Tailwind CSS via CDN), Vanilla JavaScript (ES6+).
- **QR Code Generator**: `qrcode` (Node.js npm package) rendered onto HTML5 Canvas / SVG.

3. SECURITY & CRYPTOGRAPHIC DESIGN (ANTI-FORGERY MECHANISM)
The Threat Model:
Students must not be able to counterfeit badges, edit another student's Massar number, create fake QR codes, or screenshot another student's badge to gain unauthorized attendance entry.

Encryption Protocol (AES-256-CBC + HMAC):
Payload Structure:

JSON
{
  "studentId": "STU_892341",
  "massar": "G134098765",
  "clubYear": "2026-2027",
  "createdTimestamp": 1728057600000,
  "nonce": "a7f3b901e4"
}
Encryption Process:

Stringify payload JSON.

Encrypt payload using AES-256-CBC with ENCRYPTION_SECRET_KEY and a random Initialization Vector (IV).

Compute HMAC-SHA256 signature over the ciphertext to ensure tamper protection.

Output string format encoded as Base64URL: IV_Hex:HMAC_Hex:Ciphertext_Base64.

QR Code Payload:
The generated QR code contains ONLY the Base64URL encrypted string (e.g., 8f3a1b...:c901e4...:U2FsdGVkX19xZ8v...).

Third-Party Scanner Behavior:
If a student or external camera scans the QR code, it displays an unreadable, meaningless encrypted hash string. No personal data, Massar code, or student name is exposed.

Admin Web Scanner Behavior:
When scanned via the admin browser scanner:

Client sends ciphertext string to backend endpoint /api/attendance/scan.

Backend checks HMAC signature for integrity.

Backend decrypts ciphertext using ENCRYPTION_SECRET_KEY.

Backend fetches student profile from the database matching studentId and massar.

If payload is valid and HMAC matches: Return HTTP 200 with Student details, Parental Authorization flag (A1/A2), and record attendance timestamp.

If payload is modified or corrupted: Return HTTP 400 ❌ FORGERY DETECTED / INVALID QR CODE.

Step 2: config/crypto.js (The Core Security Engine)
JavaScript
const crypto = require('crypto');

const ALGORITHM = 'aes-256-cbc';
const SECRET_KEY = process.env.ENCRYPTION_SECRET_KEY || 'default_secret_key_32_bytes_len!!'; // Must be 32 bytes
const IV_LENGTH = 16;

/**
 * Encrypts student object into a secure ciphertext string with HMAC verification.
 */
function encryptStudentPayload(payload) {
  const iv = crypto.randomBytes(IV_LENGTH);
  const cipher = crypto.createCipheriv(ALGORITHM, Buffer.from(SECRET_KEY, 'utf-8').subarray(0, 32), iv);
  
  let encrypted = cipher.update(JSON.stringify(payload), 'utf8', 'base64');
  encrypted += cipher.final('base64');
  
  const ivHex = iv.toString('hex');
  
  // Calculate HMAC for tamper protection
  const hmac = crypto.createHmac('sha256', SECRET_KEY);
  hmac.update(ivHex + encrypted);
  const hmacHex = hmac.digest('hex');

  // Format: IV:HMAC:ENCRYPTED_DATA
  return `${ivHex}:${hmacHex}:${encrypted}`;
}

/**
 * Decrypts and validates QR ciphertext token.
 */
function decryptStudentPayload(token) {
  try {
    const parts = token.split(':');
    if (parts.length !== 3) return { valid: false, error: 'Malformed token structure' };

    const [ivHex, hmacHex, encryptedText] = parts;

    // Verify HMAC
    const hmac = crypto.createHmac('sha256', SECRET_KEY);
    hmac.update(ivHex + encryptedText);
    const calculatedHmac = hmac.digest('hex');

    if (calculatedHmac !== hmacHex) {
      return { valid: false, error: 'Tamper detected / Invalid signature' };
    }

    // Decrypt
    const iv = Buffer.from(ivHex, 'hex');
    const decipher = crypto.createDecipheriv(ALGORITHM, Buffer.from(SECRET_KEY, 'utf-8').subarray(0, 32), iv);
    
    let decrypted = decipher.update(encryptedText, 'base64', 'utf8');
    decrypted += decipher.final('utf8');

    return { valid: true, payload: JSON.parse(decrypted) };
  } catch (err) {
    return { valid: false, error: 'Decryption failed: ' + err.message };
  }
}

module.exports = { encryptStudentPayload, decryptStudentPayload };
